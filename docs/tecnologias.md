# 📋 Padrões Adotados

- ✅ HTML5 Semântico
- ✅ Mobile First
- ✅ CSS organizado por seções
- ✅ Bulma como framework principal
- ✅ CSS personalizado somente quando necessário
- ✅ JavaScript separado do HTML
- ✅ Estrutura de arquivos padronizada
- ✅ Código comentado apenas quando agrega valor


```html

src="https://use.fontawesome.com/releases/v5.15.4/js/all.js">
</script>
```
